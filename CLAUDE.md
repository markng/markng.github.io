# markng.github.io

Personal GitHub Pages site for Mark Ng.

## Tech Stack

- **HTML** - Static pages
- **CSS** - Styling
- **GitHub Pages** - Hosting

## Project Structure

```
.
├── index.html          # Homepage
├── business_hours.html # Business hours page
└── CNAME              # Custom domain (if configured)
```

## Development

This is a static site with no build process. Edit HTML/CSS files directly.

```bash
# Preview locally (requires Python)
python -m http.server 8000

# Or with Node
npx serve .
```

## Deployment

Push to `main` branch to deploy automatically via GitHub Pages.

## Notes

- Keep pages lightweight and fast-loading
- No JavaScript required for basic functionality
- Mobile-responsive design encouraged
